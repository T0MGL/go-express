# Go Express — Sistema de Rastreo de Paquetería

Sistema profesional de tracking y gestión de envíos.

## Tech Stack

- Vite + React 18 + TypeScript
- shadcn/ui + Radix UI
- Tailwind CSS
- TanStack Query v5
- React Router v6
- React Hook Form + Zod

## Setup

Requires Node.js and npm.

```sh
npm install
npm run dev      # Dev server at http://localhost:8080
npm run build    # Production build
npm run lint     # ESLint
npm run preview  # Preview production build
```
